# Data Analytics Internship Projects

This repository contains all tasks completed during my Data Analytics Internship. The projects involve Data Analysis, Machine Learning, Natural Language Processing (NLP), and Business Intelligence using Power BI.

## Tasks Included

### Task 1: FIFA World Cup Data Analysis
- Performed Exploratory Data Analysis (EDA) on FIFA World Cup dataset.
- Analyzed team performance, goals, and tournament trends.
- Created visualizations using Python libraries.

### Task 2: Machine Learning on FIFA Dataset
- Applied machine learning techniques on FIFA dataset.
- Performed data preprocessing, feature selection, model training, and evaluation.
- Compared model performance using appropriate metrics.

### Task 3: Amazon Review Sentiment Analysis
- Conducted sentiment analysis on Amazon customer reviews.
- Performed text preprocessing and feature extraction.
- Built a classification model to predict review sentiment.

### Task 4: Power BI Dashboard
- Designed an interactive dashboard in Power BI.
- Created visualizations, KPIs, and business insights.
- Used filters and charts for data-driven decision making.
